# Outside Match Evidence | release 0.1.0

**Scope:** One bounded evidence release on Draft Pages, initially three source-linked European appearances for GW13. Official Draft waiver and lineup times were checked against `events.data` in the Draft bootstrap. An outside appearance is not a league start forecast. No model, snapshot schema, collector, source accounts, manager state, or team actions change.

**Record renewal:** Verify the competition, day, opponent, start/substitution status and official report before editing. For this pilot match by current Draft ID, club abbreviation and displayed name; the initial joins were checked against the normalized Draft dashboard data. Do not fuzzy join or infer an appearance from a squad-only team sheet. Don't label a substitution minute as playing time. Check the current official Draft waiver and lineup cutoff independently and stamp verified UTC review time. Checked-at must not be backdated to game time. Keep data hand-reviewed and bounded. Do not change an old release's locked forecast or include raw feeds, manager information, credentials, or odds.

**Roll forward:** Prepare a dedicated PR from current main. Extend the source allowlist only after verification. For the next release, use the first eligible European decision window and compare the same marginal cases before and after checking official outside evidence. Freeze inputs before each actual decision cutoff and verify league starts, 60-minute outcomes and coverage after finalization. The experiment can remain evidence-only until prospective results justify changing the model.

**Roll back:** Change `RELEASE.enabled` to `false` in `public/outside-evidence-v01.js` and bump its script URL in `public/index.html`, or revert this entire release PR. The optional drawer hook also handles script removal. Deploy Pages and verify the drawer lacks the panel while official lineups, scores and waiver recommendations remain present. No data migration, collector restart, or snapshot rollback is required. Missing/expired records hide the panel automatically.
