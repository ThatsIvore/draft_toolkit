Standard FPL Private Snapshot Helper

Capture the minimum current squad state needed by the private Standard FPL analysis, without giving the toolkit your login or exporting account identity.

2. Capture in two clicks

  1. Sign in manually at the official FPL site. The helper never handles the sign-in.
  2. Open Pick Team, select List view and Selling Price, and make sure there are no unsaved lineup changes.
  3. Click Capture FPL snapshot. It validates 15 players, lineup order, captaincy, exact prices and chip state, then opens Transfers.
  4. On Transfers, make sure there are no pending transfers and click the bookmark again. A small read-only Transfer History window opens briefly, closes itself, and a private JSON file downloads to your computer.
  5. Move that file to data/private/current-team.json before running the Standard FPL command.

Privacy boundary

The helper reads only rendered squad, price, transfer, finance and chip fields. It never reads a password, token, cookie, account profile, existing browser-storage key or private API response. Its only programmatic data request is the public player list with credentials explicitly omitted; the second pass briefly opens your visible public Transfer History page to read its summary.

Between the two clicks it keeps one helper-owned, sanitized session value containing player IDs and allowed team state. It deletes that value after success or any error. The downloaded JSON excludes account and entry identifiers, names and clubs, and it never leaves your browser unless you move it yourself.

Experimental limitations

This personal helper depends on the current official FPL page labels and markup and may stop safely after a site update. It needs permission to open its small same-site Transfer History window. It supports the 2026/27 two-chip-set rule, assigns set 1 through Gameweek 19 and set 2 thereafter, and refuses incomplete or ambiguous state. It never presses Save Team, Make Transfers or a chip control.

This is not the future paid onboarding flow. A hosted Connect FPL experience still requires Premier League permission and a registered integration.
