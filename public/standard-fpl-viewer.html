How do I create the report?
  1. Use the private snapshot helper while signed in to FPL.
  2. Move its downloaded JSON to data/private/current-team.json.
  3. Run the documented Standard FPL command with FPL_STANDARD_PRIVATE_SNAPSHOT set.
  4. Choose the resulting standard-fpl-poc.json here.

Privacy boundary

This page has no report endpoint, account connection, analytics or browser storage. It reads the file you select into this tab’s memory, validates its private-report shape and renders it locally. Refreshing or pressing Clear removes it.

The shared Draft dashboard remains separate. This testing page is not the future hosted Standard FPL mode or a commercial onboarding flow.
